# Resources

The game still has a physical resource economy.

Examples include:

* wood
* stone
* crystals
* magical materials
* environmental resources

The difference is how the player obtains them.

They aren't simply mining because survival games need mining.

They are learning **how magic interacts with matter**.

That keeps resource gathering tied to the game's core fantasy.
