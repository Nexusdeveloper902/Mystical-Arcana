# UI identity

The UI needs to visually belong to the same universe.

The planned HUD contains:

* health
* mana
* equipped runes
* quick-spell wheel

with tooltips for runes and schematics. 

The UI should feel like an **arcane instrument**, not a modern videogame overlay.

### Visual characteristics

* rune-inspired geometry
* restrained magical illumination
* clean hierarchy
* readable typography
* subtle transparency
* stone/crystal/metal motifs where appropriate
* magical symbols used as functional indicators
* minimal clutter

The interface should never overpower the world.
