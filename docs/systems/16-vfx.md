# VFX identity

VFX are a huge part of the project's visual signature.

The goal is:

**light + particles + geometry + motion**

rather than simply:

**particle explosion.**

Magic should have shapes.

Runes should form.

Energy should flow.

Projectiles should have trails.

Impacts should feel physical.

Environmental mana should move subtly.

The development checklist explicitly calls for VFX trails, impact effects, and eventual VFX pooling for performance.
