# Inventory

The inventory provides the practical backbone of the survival system.

It handles:

* physical resources
* magical materials
* rune-related items
* tablets
* other collectible objects

Resources can be gathered and added to inventory.

The development plan explicitly calls for pickup objects that feed into the player's inventory. 

But the inventory should remain subordinate to the game's magical identity.

We're not trying to create a spreadsheet simulator.

The inventory exists so that the player can **carry the ingredients required to interact with the world**.
